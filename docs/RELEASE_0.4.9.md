# Dancing Line Assist Release

发布日期：2026-09-17

## 附件

- `DancingLine-Community-Assist-0.4.9.zip`：社区版，含怀旧皮肤自动游玩兼容。
- `DancingLine-Steam-Assist-0.2.9.zip`：官方 Steam 版，含引导线显示与双路径关卡识别。

两个附件的内存布局、DLL 校验与启动流程不同，必须按游戏版本选择，不能混用。

## 社区版 0.4.9

- 新增对怀旧皮肤 `GameCharacterClassic` 的自动游玩兼容。
- 等待绑定时记录角色类型、当前角色所属关卡和引导点所属关卡，方便排查未按键原因。
- 修正 0.4.9 测试包启动窗口提示中的 PowerShell 引号错误。

## Steam 版 0.2.9

- 引导线显示、解除关卡限制和自动游玩均已实测成功。
- 识别优先使用 `GameCharacter`，未绑定时从 Steam 版关卡注册表取得 `LevelBase`，进入关卡未移动即可识别。
- 默认开启引导线是可选项；自动游玩前必须确认路线实际显示。

## 已验证

- 社区版：用户已使用怀旧皮肤完成一次通关。
- Steam 版：用户确认自动游玩成功通关。

## 使用

1. 下载并完整解压与游戏版本相符的附件。
2. 启动游戏后运行附件内的 `Start.cmd`。
3. 开启或确认引导线实际显示，进入关卡后识别，再启动自动游玩并手动开始。

## 注意

- 仅适配 README 所列 DLL 校验对应的 Windows 64 位社区版。
- 不包含游戏、DLL、资源、存档、日志、录像或第三方模组。
- 自动游玩仍是实验功能；遇到不支持的路线请按 F8 停止。
