# 开发记录

## 当前实现

以 0.4.5 用户测试包的四个程序文件为初始源码，保持字节不变。

引导线控制修改两个经校验的方法返回值；写入后验证并恢复内存保护。自动游玩读取进程并经 SendInput 发送空格。
引导点通过事件订阅对象发现，队列遍历替代早期固定深度扫描，扫描受预算约束。
首次识别以引导点所属关卡为入口，实际开始后绑定匹配的玩家。
世界坐标按此版本 Unity Transform 的父级位置、旋转和缩放计算，不调用游戏内部函数。
位置触发检查前向距离、横向偏差、时间窗口及运动状态；落地等待、传送疑似检测与对齐等待均保留待执行点。

## 已知限制

外部读内存不是原子快照。键盘输入跨线程、跨帧，调度延迟会影响转向。
引导点不一定就是道路几何中心。当前位置模式不是地图寻路器。
传送检测为启发式，短距离传送或动态路径可能漏判。对齐等待有超时。
地面/跳跃逻辑和所有偏移仅针对校验通过的游戏二进制。
