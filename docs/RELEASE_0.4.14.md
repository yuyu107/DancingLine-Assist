# Dancing Line Assist 0.4.14

发布日期：2026-09-17

## Release 附件

- `DancingLine-Assist-0.4.14.zip`
  - `Community/`：社区版 0.4.14。
  - `Steam/`：官方 Steam 版 0.2.9。
  - 两个目录分别运行各自的 `Start.cmd`，不可混用。

本附件不包含游戏本体、DLL、资源、存档、日志、录像或第三方模组。

## 社区版 0.4.14

- 支持普通角色和怀旧皮肤角色。
- 对检测到角色进度与音乐时钟相差约 1 秒的路线，改用世界坐标连续判断转角。
- 对少数未标记的紧接转角，可补发一次按键且不跳过下一正常提示点。
- 用户已在“数学”关卡实测通关。

## Steam 版 0.2.9

- 保留已验证的引导线开启和自动游玩实现。
- Steam 版与社区版内存布局不同，必须使用对应目录。

## 说明

自动游玩仍是实验功能，仅供个人测试、无障碍辅助和技术研究。请勿将自动结果冒充为人工成绩，也请勿以本项目向官方、开发者或发行方施压、挑衅或索要支持。
