# Steam Assist 0.2.9

适用于本仓库 README 所列校验对应的官方 Steam 版《跳舞的线》。这是与社区版独立的工具，不能混用。

## 已验证功能

- 显示引导线与解除关卡限制。
- 识别当前关卡与引导点。
- 自动游玩实测通关。

## 使用

1. 完整解压附件后运行 `Start.cmd`。
2. 先应用引导线设置；默认开启为可选项。
3. 进入关卡后，确认引导线实际显示，再识别并启动自动游玩。
4. 切回游戏后手动开始或继续；F8 停止。

## 注意

- 如果开关显示开启但路线没有出现，请在游戏内关闭再开启一次。
- 本工具不会修改磁盘 DLL；重启游戏后内存补丁失效。
- 不包含游戏、DLL、资源、存档、日志、录像或第三方模组。
