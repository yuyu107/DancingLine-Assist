# Dancing Line Assist

《跳舞的线》引导线与自动游玩实验工具，分别支持**社区版 0.4.9**与**官方 Steam 版 0.2.9**。

提供引导线控制、关卡识别和基于引导点世界坐标的实验性自动转向。仅适配 README 所列校验对应的 Windows 64 位构建，不保证适配其他版本或所有关卡。

## 使用

1. 下载本仓库 ZIP 并完整解压，保留源码与启动脚本在同一目录。
2. 启动游戏，运行 `Start.cmd`。需要 Windows 自带的 64 位 Windows PowerShell。
3. 点击“启用免费引导线”，进入关卡后点击“识别当前关卡”。首次识别不再要求故意死亡。
4. 点击“启动自动游玩”，切回游戏并手动开始。
5. **F8** 或窗口内停止按钮停止自动点击；关闭窗口也会释放按键。
6. 失败时点击“导出运行日志”，日志保存在工具目录。

测试时使用：游戏内“自动调整”和“自动修正音频输出延迟”开启，工具窗口偏移 **-50 毫秒**。这是已测试配置，不保证适用于全部关卡。

窗口偏移只移动时间校验窗口；当前版本主要根据位置触发空格，不是单纯按时间表点击。

## 功能

### 1. 开启引导线

- 允许在原本受限制的关卡中开启并显示引导线。
- 可在工具中应用设置或恢复原规则；修改仅存在于游戏运行内存，重启游戏后自动失效，不修改磁盘 DLL。
- Steam 版若开关显示开启但路线没有出现，请在游戏内关闭再开启一次。

### 2. 自动游玩

- 识别当前关卡的引导点，在接近转向位置时自动发送按键。
- 进入关卡后依次点击“识别当前关卡”和“启动自动游玩”，再回到游戏手动开始或继续；按 **F8** 可随时停止。
- 换关后必须重新识别；自动游玩依赖引导线实际显示。

> [!CAUTION]
> 自动游玩功能仅供个人测试、无障碍辅助和技术研究使用。
>
> 请勿将自动游玩产生的通关结果、进度、截图、录像或成绩冒充为人工完成的成果，用于误导他人、炫耀或不当获利。
>
> 本工具为实验性辅助功能，不代表使用者的实际操作水平；使用者应自行承担使用和传播相关内容的责任。

## 限制

- 自动游玩仍为实验功能；动态路线、窄路、传送、空中转向和引导线外钻石等场景不保证成功。
- 不会自动规划绕路吃钻石、录制手动路线或强制纠正角色位置。
- 仅支持 README 中列出的文件校验对应版本；不匹配时请勿删除校验强行运行。

## 文件

- `AutoPlayer.cs`：扫描、位置计算、自动输入及诊断。
- `HintMemory.cs`：带版本和字节校验的引导线内存补丁。
- `Start.ps1` / `Start.cmd`：Windows 窗口和启动入口；启动时通过 Add-Type 编译 C#。
- [`steam/`](steam/)：Steam 版 0.2.9 的独立源码、启动文件及说明；不覆盖社区版文件。
- [开发记录](docs/DEVELOPMENT.md)：实现思路、限制与后续工作。
- [更新记录](CHANGELOG.md)：主要里程碑。

日志可能包含进程地址和路径，默认忽略，不随源码提交。仓库不包含游戏程序、DLL、资源、存档或第三方模组安装包。
