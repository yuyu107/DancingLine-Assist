# Dancing Line Assist

《跳舞的线》引导线与自动游玩实验工具，分别支持**社区版 0.4.36**与**官方 Steam 版 0.3.36**。

提供引导线控制、关卡识别和基于引导点世界坐标的实验性自动转向。仅适配 README 所列校验对应的 Windows 64 位构建，不保证适配其他版本或所有关卡。

> [!WARNING]
> 本项目为非官方、实验性的本地辅助工具，仅供兼容性研究、个人测试和学习用途。
>
> 本项目不隶属于、未获任何游戏开发者或发行方认可。请遵守你所在地区的法律、游戏平台规则及游戏许可协议；使用本项目产生的风险由使用者自行承担。
>
> 本项目不包含游戏本体、游戏资源、DLL、存档或第三方模组。

## 使用方法

### 1. 下载并启动对应版本

从 [Releases](https://github.com/yuyu107/DancingLine-Assist/releases) 下载 `DancingLine-Assist-v0.5.1.zip`，完整解压后按游戏版本选择目录：

| 游戏版本 | 启动文件 |
| --- | --- |
| 社区版 | `Community/Start.cmd` |
| 官方 Steam 版 | `Steam/Start.cmd` |

先启动游戏，再双击对应的 `Start.cmd`。需要 64 位 Windows PowerShell；请保留同目录中的所有文件，不要直接在压缩包中运行或只复制启动脚本。

如果下载的是仓库源码，社区版启动文件在根目录，Steam 版在 `steam/`，与 Release 压缩包的目录结构不同。

### 2. 开启引导线

- **社区版**：点击工具中的“启用免费引导线”，再进入关卡。进入后可通过游戏内开关控制引导线。
- **Steam 版**：点击“应用引导线设置”，进入关卡后在游戏内开启引导线。如果希望尝试进关默认开启，可先勾选“进入关卡时尝试默认开启”，再应用设置。若开关显示已开但没有路线，请在游戏内关闭后再开启一次。

建议确认关卡中已经实际显示引导线，再使用自动游玩。Steam 版识别会直接读取内部引导点，关闭引导线时也可能成功，但不保证所有关卡适用。只想开启引导线时，完成这一步即可。

### 3. 启动与停止自动游玩

1. 进入需要游玩的关卡，可在尚未开始走动时操作。
2. 点击“1. 识别当前关卡”，或按 **F6**，等待识别成功。
3. 点击“2. 启动自动游玩”，或按 **F7**。
4. 切回游戏窗口，手动开始或继续游戏；保持游戏在前台。
5. 按 **F8** 或点击“停止自动游玩（F8）”停止自动点击。关闭工具窗口也会停止；中途停止后也可按 **F7** 恢复。

更换关卡后，先停止自动游玩，再重新识别新关卡。若提示关卡数据变化或需要重新识别，请按提示操作。

需要手动绕路吃钻石时，可先停止自动游玩，手动回到引导线路线上后再次启动。工具会尝试按角色当前位置重新定位到最近的路线点；若提示找不到合理路线点，请不要强行启动，回到更靠近引导框的位置后再试。

### 4. 参数与问题反馈

首次使用先保留默认参数：

| 选项 | 默认值 / 说明 |
| --- | --- |
| 时间窗口偏移 | **-50 毫秒**；调整时间校验窗口，不等于每次按键都提前 50 毫秒 |
| 按键提前量 | **20 毫秒**；严格路段可尝试 **5 毫秒** |
| 跳过直行落点提示 | 默认勾选，属于实验选项；修改后需重新启动自动游玩 |
| 游戏内状态遮罩 | 默认开启；显示工具运行状态与 F6/F7/F8 提示，仅在游戏窗口前台显示。关闭前会提示：录制或分享自动游玩内容时，应自行明确标注自动游玩。 |

社区版测试时曾同时开启游戏内“自动调整”和“自动修正音频输出延迟”；具体关卡表现请查看下方测试记录。

如出现漏转、误点或识别失败，请点击“导出运行日志”。日志保存在当前工具目录，反馈时请附上日志、游戏版本、关卡名称，以及出错位置的截图或录像。

引导线设置只作用于本次游戏运行，重启游戏后需要重新应用。“恢复引导线原规则”只恢复引导线相关设置；要停止自动点击，请使用停止按钮或 **F8**。

## 功能

### 1. 开启引导线

- 允许在原本受限制的关卡中开启并显示引导线。
- 可在工具中应用设置或恢复原规则；修改仅存在于游戏运行内存，重启游戏后自动失效，不修改磁盘 DLL。
- Steam 版若开关显示开启但路线没有出现，请在游戏内关闭再开启一次。

### 2. 自动游玩

- 识别当前关卡的引导点，在接近转向位置时自动发送按键。
- 进入关卡后按 **F6** 识别、按 **F7** 启动或恢复，再回到游戏手动开始或继续；按 **F8** 可随时停止。
- 换关后必须重新识别；建议开启引导线以便观察路线与排查问题。

> [!CAUTION]
> 自动游玩功能仅供个人测试、无障碍辅助和技术研究使用。
>
> 请勿将自动游玩产生的通关结果、进度、截图、录像或成绩冒充为人工完成的成果，用于误导他人、炫耀或不当获利。
>
> 本工具为实验性辅助功能，不代表使用者的实际操作水平；使用者应自行承担使用和传播相关内容的责任。

## 限制

- 自动游玩仍为实验功能；动态路线、窄路、传送、空中转向和引导线外钻石等场景不保证成功。
- 不会自动规划绕路吃钻石、录制手动路线或强制纠正角色位置。
- 仅支持 README 中列出的文件校验对应版本；不匹配时请勿删除校验强行运行。

## 文件

- `AutoPlayer.cs`：扫描、位置计算、自动输入及诊断。
- `HintMemory.cs`：带版本和字节校验的引导线内存补丁。
- `Start.ps1` / `Start.cmd`：Windows 窗口和启动入口；启动时通过 Add-Type 编译 C#。
- [`steam/`](steam/)：Steam 版 0.2.9 的独立源码、启动文件及说明；不覆盖社区版文件。
- [开发记录](docs/DEVELOPMENT.md)：实现思路、限制与后续工作。
- [更新记录](CHANGELOG.md)：主要里程碑。

日志可能包含进程地址和路径，默认忽略，不随源码提交。仓库不包含游戏程序、DLL、资源、存档或第三方模组安装包。
