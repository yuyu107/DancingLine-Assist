# Dancing Line Assist

《跳舞的线》引导线与自动游玩实验工具，分别支持 **社区版 0.4.14** 与 **官方 Steam 版 0.2.9**。

提供引导线控制、关卡识别和基于引导点世界坐标的实验性自动游玩功能。仅适配 README 所列校验对应的 Windows 64 位构建，不保证适配其他版本或所有关卡。

## 功能

### 1. 引导线

- 允许在原本受限制的关卡中开启并显示引导线。
- 可在工具中应用设置或恢复原规则。
- 修改仅作用于当前游戏进程内存，重启游戏后自动失效，不修改磁盘 DLL。
- Steam 版若开关显示已开启但路线没有出现，请在游戏内关闭后再开启一次。

### 2. 自动游玩

- 识别当前关卡的引导点，并根据角色位置和引导点世界坐标，在接近转向位置时自动发送按键。
- 进入关卡后依次执行“识别当前关卡”和“启动自动游玩”，再回到游戏手动开始或继续。
- 按 **F8** 可随时停止自动点击，关闭工具窗口也会停止。
- 换关后必须重新识别。
- 自动游玩依赖引导线已经实际显示。

自动游玩主要用于按照游戏现有引导线路线进行实验性测试，并不是完整的 AI 寻路系统。

## 使用方法

### 1. 下载并启动对应版本

从 [Releases](https://github.com/yuyu107/DancingLine-Assist/releases) 下载 `DancingLine-Assist-0.4.14.zip`，完整解压后按游戏版本选择目录：

| 游戏版本 | 启动文件 |
| --- | --- |
| 社区版 | `Community/Start.cmd` |
| 官方 Steam 版 | `Steam/Start.cmd` |

先启动游戏，再双击对应的 `Start.cmd`。

工具需要 **64 位 Windows PowerShell**。请保留同目录中的所有文件，不要直接在压缩包中运行，也不要只复制启动脚本。

如果下载的是仓库源码，社区版启动文件在根目录，Steam 版在 `steam/`，与 Release 压缩包的目录结构不同。

### 2. 开启引导线

#### 社区版

点击工具中的“启用免费引导线”，再进入关卡。

进入后可通过游戏内开关控制引导线。

#### Steam 版

点击“应用引导线设置”，进入关卡后在游戏内开启引导线。

如果希望尝试进关默认开启，可先勾选“进入关卡时尝试默认开启”，再应用设置。

若开关显示已开启但没有路线，请在游戏内关闭后再开启一次。

> [!IMPORTANT]
> 使用自动游玩前，请确认关卡中已经**实际显示引导线**。
>
> 如果只需要引导线功能，完成这一步即可。

### 3. 启动与停止自动游玩

1. 进入需要游玩的关卡，可以在尚未开始走动时操作。
2. 点击“1. 识别当前关卡”，等待识别成功。
3. 点击“2. 启动自动游玩”。
4. 切回游戏窗口，手动开始或继续游戏，并尽量保持游戏在前台。
5. 按 **F8** 或点击“停止自动游玩（F8）”停止自动点击。

关闭工具窗口也会停止自动点击。

更换关卡后，先停止自动游玩，再重新识别新关卡。若提示关卡数据变化或需要重新识别，请按提示操作。

### 4. 手动操作后继续

自动游玩不会主动规划引导线路线之外的路线。

需要手动绕路吃钻石时，可以：

**停止自动游玩 → 手动操作 → 回到正常引导线路线附近 → 再次启动自动游玩**

部分位置已经验证可以正常重新衔接，但不保证所有位置都能恢复自动游玩。

## 参数与问题反馈

首次使用建议先保留默认参数：

| 选项 | 默认值 / 说明 |
| --- | --- |
| 时间窗口偏移 | **-50 毫秒**；调整时间校验窗口，不等于每次按键都提前 50 毫秒 |
| 按键提前量 | **20 毫秒**；严格路段可尝试 **5 毫秒** |
| 跳过直行落点提示 | 默认勾选，属于实验选项；修改后需重新启动自动游玩 |

社区版测试时曾同时开启游戏内“自动调整”和“自动修正音频输出延迟”；具体关卡表现请查看下方测试记录。

如果出现漏转、误点、提前或延迟转向、识别失败等问题，请点击“导出运行日志”。

日志保存在当前工具目录。反馈时建议同时提供：

- 游戏版本
- 关卡名称
- 导出的运行日志
- 出错位置的截图或录像

引导线设置只作用于本次游戏运行，重启游戏后需要重新应用。“恢复引导线原规则”只恢复引导线相关设置；要停止自动点击，请使用停止按钮或 **F8**。

> [!NOTE]
> 日志可能包含进程地址和本地文件路径，默认忽略，不随源码提交。

## 限制

自动游玩仍为实验功能，不保证所有关卡都能完整自动通关。

目前尤其需要注意：

- 动态路线
- 窄路
- 传送
- 空中转向
- 特殊机关
- 引导线外钻石
- 需要主动绕路的收集路线
- 游戏物理或角色位置出现异常的情况

自动游玩不会：

- 自动规划绕路吃钻石
- 录制玩家的手动路线
- 强制纠正角色位置
- 保证从任意位置重新接管
- 保证所有关卡无失误通关

仅支持 README 中列出的文件校验对应版本；不匹配时请勿删除校验强行运行。

## 文件

- `AutoPlayer.cs`：扫描、位置计算、自动输入及诊断。
- `HintMemory.cs`：带版本和字节校验的引导线内存补丁。
- `Start.ps1` / `Start.cmd`：Windows 窗口和启动入口；启动时通过 Add-Type 编译 C#。
- [`steam/`](steam/)：Steam 版 0.2.9 的独立源码、启动文件及说明；不覆盖社区版文件。
- [开发记录](docs/DEVELOPMENT.md)：实现思路、限制与后续工作。
- [更新记录](CHANGELOG.md)：主要里程碑。
